# Guessing Game

A simple number guessing game written in Rust.

## Description

This is a learning project for Rust. The program generates a random number between 1 and 100, and the player tries to guess it.

## How to Play

1. Run the program with `cargo run`
2. Enter a number when prompted
3. The program will tell you if your guess is too small, too big, or correct
4. Keep guessing until you win!

## Features

- Random number generation
- Input validation
- Helpful feedback on each guess

## Building

```bash
cargo build
```

## Running

```bash
cargo run
```
